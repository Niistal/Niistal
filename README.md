## 🏢 What I do

<img align="right" width="280" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="coding"/>

**Enterprise Software Developer @ GIP** — I build and modernize real business systems in the Microsoft ecosystem.

Currently working on **Citrino** ([citrino.solutions](https://citrino.solutions/)), an enterprise platform to digitalize sales, purchasing, production, logistics, admin, HR and quality — plus industrial software for **SITAB** ([sitab.es](https://sitab.es/), office partition systems).

My style: **pragmatic, not hype-driven.** Keep what works, improve what adds value, migrate legacy gradually when there is clear technical/business advantage.

- 🧩 ERP modules, business logic, WinForms + ASP.NET Core, REST integrations
- 🗄️ SQL Server, T-SQL, stored procedures, ODBC, data integrity + traceability
- 🔧 Legacy maintenance (.NET Framework 4.7.2/4.8, VB.NET) → progressive migration to .NET 8
- 🔒 Secure by design: OWASP, validation, least privilege, secrets, API/DB security
- 📊 Now expanding to AI + Big Data applied to ERP data: automation, insights, decisions
